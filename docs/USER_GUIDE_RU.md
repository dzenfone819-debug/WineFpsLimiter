# Руководство пользователя

FPS Limiter & Overlay позволяет ограничивать частоту кадров в играх для плавности картинки и снижения нагрузки на систему, а также выводит полезную информацию поверх игры.

## Быстрый старт

1.  **Запуск**: Откройте папку с программой (выберите `x64` или `x86` в зависимости от разрядности вашей игры). Запустите `FPSLauncher.exe`.
2.  **Добавление игры**:
    *   Нажмите кнопку `+ Add`.
    *   Выберите `.exe` файл вашей игры.
    *   Игра появится в списке слева. Иконка подгрузится автоматически.
3.  **Настройка**:
    *   Выберите игру в списке.
    *   **Enable Limit**: Включает ограничение FPS.
    *   **Target FPS**: Желаемое количество кадров (например, 60).
    *   **Background Limit**: Ограничение FPS, когда игра свернута (полезно для стримеров или чтобы не греть карту, пока вы в браузере).
    *   **Overlay**: Настройте отображение часов (`Show Clock`) и таймера сессии (`Session Timer`).
    *   **Toggle Key**: Кнопка для открытия меню прямо в игре (по умолчанию `Shift+Tab`).
    *   **Start Visible**: Если галочка снята, меню оверлея будет скрыто при старте (включается по хоткею).
4.  **Запуск игры**:
    *   Нажмите синюю кнопку `LAUNCH GAME`.
    *   Лаунчер свернется, игра запустится, и вы увидите оверлей в углу экрана.

## Управление в игре

*   Нажмите назначенную клавишу (например, `Shift+Tab`), чтобы открыть/закрыть меню настроек.
*   Меню позволяет менять лимит FPS на лету без перезапуска игры.
*   Позиция виджетов (часы/таймер) закреплена в правом верхнем углу.

## Решение проблем

**Оверлей не появляется:**
1.  Убедитесь, что вы используете правильную версию (x64 для 64-битных игр).
2.  Некоторые игры с анти-читами могут блокировать инжекцию DLL.
3.  Если игра вылетает при запуске, попробуйте отключить сторонние оверлеи (Discord, Steam, NVIDIA).

**Совместимость с Mac/Linux:**
Приложение прекрасно работает через CrossOver, Whisky, Porting Kit и Proton. Клавиши управления адаптированы для клавиатур MacBook (Backspace / Shift+Tab).
